Range games

  1. First: select the number of players.
  2. Second: select how many rounds for this session (default of 3).
  3. Third: select how many balls each player gets.
  4. Fourth: update player names as needed.
  5. Fifth: mark the four corners of the range (tee left, tee right, far right, far left). The map turns so the tee box sits at the bottom of the phone. Then mark the PIN.

Stay in the hitting bay. Mark the landing from the tee line. Do not walk down the range.
